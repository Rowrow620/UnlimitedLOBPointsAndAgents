===================================================
 Unlimited LOB Points & Agents Mod
 For Lobotomy Corporation (BaseMod 5.0)
===================================================

Features:
- Locks LOB Points to 999,999 (displays as ∞).
- Disables LOB Point deductions on hiring/customizing agents.
- Removes daily agent hiring quota limits (allows hiring unlimited agents on any day).

Installation:
1. Extract the "UnlimitedLOBPoints" folder from this zip file.
2. Place the "UnlimitedLOBPoints" folder into your game's BaseMods directory:
   LobotomyCorp_Data\BaseMods\UnlimitedLOBPoints\

3. Launch Lobotomy Corporation (or use Lobotomy Mod Manager to enable it).

Requirements:
- BaseMod 5.0 (or higher)
